This document merges the four program comparisons (Production Awards baseline, Wijhat, Stand for Art, Abbara) into one master table. Side by side, it lays out what each program contains, what is shared, where they diverge, and — for each divergence — which program is the source. It does **not** propose blocks; it feeds the component breakdown that does.

Sources: the four program audits — Content Audit — Production Awards · Content Audit — Wijhat · Content Audit — Stand for Art · Content Audit — Abbara

Programs abbreviated below: **PA** = Production Awards · **WJ** = Wijhat · **SFA** = Stand for Art · **AB** = Abbara.

## 3. Divergence map — where the programs pull apart

Six fields cannot be single-shape across the four programs. For each, the programs diverge enough that the kit will need to absorb several distinct treatments — whether as one flexible block or as separate blocks is a call for the component breakdown, not something this matrix decides.

### 3.1 Key-dates field — 4 divergent shapes

- **Single annual call** (PA): one deadline / one results date.
- **N rounds + decision aid** (WJ): 3 deadline/results pairs, rolling intake with fixed windows, plus "which round do I apply to" logic.
- **Rolling / always-open, no dates** (SFA): no deadlines, no results announcements.
- **Staged multi-phase lifecycle** (AB): phased dates across ~2–2.5 yrs (call → results → workshop 1 → agreements → workshop 2 → technical assistance → end of contracting).

### 3.2 Forms of support — 4 divergent shapes

- **Per-discipline monetary table** (PA): 5 disciplines, different caps.
- **Single itemized cap** (WJ): one ceiling, broken out by cost type.
- **No preset amount + non-monetary referral** (SFA): criteria-driven emergency fund and/or referral (residencies, recommendation letters, legal/advocacy).
- **Monetary core funding + non-monetary services bundle** (AB): €22,000 + training + technical assistance + networking, with a "what the money is/isn't for" note (excludes program activities).

### 3.3 Eligibility — 4 divergent shapes

- **Individual** (PA): age + discipline + origin.
- **Individual or group** (WJ): same, plus group-level submission rules and travel-direction geometry.
- **Individual at risk** (SFA): origin + artist/actor status + verifiable threat.
- **Organizational** (AB): org age, budget band, registration status, governance — not personal attributes.

### 3.4 Apply module — 2 route types + variant paths

- **Portal route** (PA / WJ / AB): apply.mawred.org, save/resume.
- **Non-portal, privacy-first route** (SFA): encrypted JotForm, non-resumable, confidentiality notices as first-class content.
- **Variant application paths** within one program (WJ): individual vs. group flows sharing a common core (toggle/tabs/accordion) — should not duplicate the ~80% shared content.

### 3.5 Selection block — jury vs. committee-that-sets-support

- **Jury, accept/reject against a fixed grant**: PA (3, per-discipline, yearly), WJ (3, per round), AB (5, per round).
- **Committee that also sets the level/form of support** (SFA): 6-member steering committee decides accept/reject **and** what support is offered.

### 3.6 Contractual/payment block — detailed → near-empty

- **Detailed** (PA / WJ): installments, signing window, completion window, guarantors (PA), clawback, citation/credit.
- **Near-empty** (SFA / AB-EN): SFA has none by design; AB-EN is thin (flagged as possible EN content gap — verify against AR before treating as genuine absence).
- Whatever hosts this content needs to **degrade gracefully** to almost nothing without looking broken.

## 5. Content-integrity & migration flags (site-wide, surfaced across audits)

Not structural-design issues — **migration/QA** items to fix during the build:

- **Contact mailto bugs** — WJ footer mailto points to `abbara@mawred.org` (visible text says wijhat@); SFA shows `artist@` (singular) in text but mailto resolves to `artists@` (plural). AB's abbara@ resolves correctly on its own page, confirming the WJ bug is **Wijhat-side copy/paste**, not a shared include. → site-wide contact-link QA pass.
- **RTL "?heading" artifact** — headings render with the question mark at the front ("?Who is it for", "?Who is Abbara for") on WJ and AB — a bilingual-CMS punctuation/RTL artifact. Recurring → CMS-wide fix for the EN build.
- **Empty Instagram footer embed** — stray `-->` comment visible in the global footer on SFA and AB. Seen on enough pages to treat as a **global-footer** fix, not per-page.
- **Editorial artifacts in live copy** — WJ clawback clause contains unresolved editor comments ("((OR probably clearer… ))"); WJ group flow duplicates the "purpose of intended travel" line. → content-integrity pass beyond structure.
- **Dead/placeholder links** — several AB beneficiary entries use `href="#"` (named but unlinked). → directory-block migration QA.
- **EN FAQ gap** — PA, WJ, AB all show "Available only in Arabic" empty shells; only SFA has real EN FAQ content. The gap is a **migration/content issue**, not a design default — build the FAQ block as real content.
- **Thin AB-EN contractual section** — verify against the AR page whether the missing installments/windows/guarantors/clawback/citation is a genuine absence or an EN content gap (AB plainly has contracts — signed after workshop 1).
